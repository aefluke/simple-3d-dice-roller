# Simple 3D Dice Roller

A 3D dice roller built with [Three.js](https://threejs.org/) and [cannon-es](https://github.com/pmndrs/cannon-es) physics.

## Usage

Click the button to roll the dice. The result is shown once the dice settle.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
